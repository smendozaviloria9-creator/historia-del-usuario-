# historia-del-usuario-
Para ejecutar el código de inventario.py que creamos, sigue estos pasos sencillos. No necesitas ser un experto, solo asegúrate de tener Python instalado en tu computadora.
------------------------------
1. Preparación del archivo

   1. Abre un editor de texto (como Bloc de notas, VS Code o Sublime Text).
   2. Copia el código que te proporcioné anteriormente y pégalo allí.
   3. Guarda el archivo con el nombre exacto: inventario.py.
   * Tip: Asegúrate de que la extensión sea .py y no .txt.
   
2. Abrir la terminal o consola

* En Windows: Presiona la tecla Win, escribe cmd y dale a Enter.
* En Mac/Linux: Abre la aplicación llamada Terminal.

3. Navegar a la carpeta
Debes "decirle" a la terminal dónde guardaste el archivo usando el comando cd (change directory). Por ejemplo, si lo guardaste en el escritorio:

cd Desktop

4. Ejecutar el programa
Escribe el siguiente comando y presiona Enter:

python inventario.py

(Si no funciona, intenta con python3 inventario.py).

5. ¿Qué verás al ejecutarlo? (Prueba de uso)
El programa te guiará paso a paso. Aquí tienes un ejemplo de cómo interactuar con él para cumplir con los criterios de aceptación:

   1. Nombre: Escribe algo como Lápiz.
   2. Precio: Escribe 500. (Si intentas escribir letras, verás el mensaje de error y te pedirá el dato de nuevo).
   3. Cantidad: Escribe 3.
   4. Resultado: Verás en pantalla:
   
   Producto: Lápiz / Precio: 500.0 / Cantidad: 3 / Total: 1500.0
